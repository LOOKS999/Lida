Features

Small on purpose.

Everything it does, it does quietly. Nothing to configure unless you want to.

Follows Windows

Reads your system light/dark setting and reacts within a second. No manual toggling.

Wallpaper per mode

Pick one image for light and one for dark. Lida swaps them the moment the theme changes.

Cursors per mode

Chooses cursor schemes by name from ones already installed. Handles all 17 roles.

Lock screen, too

Mirrors the active wallpaper onto the lock screen. Needs admin rights; the toggle shows the real state.

A calm interface

A rounded modern panel or the native menu. Custom colors, font and animation. Your call.

Starts with Windows

Registers itself at sign-in. Runs elevated when possible, so lock screen keeps working after a reboot.

How it works

Set it once. Then forget it.

01

03

Forget about it

Lock screen

The theme follows you to the lock screen, too.

When enabled, Lida mirrors the active wallpaper onto the Windows lock screen. The tray toggle always reflects the real registry state — not a guess — so you always know whether Lida is in control.

  • Writes HKLM\...\PersonalizationCSP with the image path and status.
  • Needs administrator rights, both to turn on and to turn off.
  • Turning it off restores your own lock screen picture.
  • For it to survive a reboot, start Lida with Windows while elevated.

FAQ

Questions, answered plainly.

Is Lida free?

Yes. It is open source under the MIT license. No paid tier, no upsell.

Does it collect data?

No. Lida has no network access and no telemetry. It reads your theme setting and writes wallpaper, cursor and lock-screen values locally.

Why does Windows warn about the download?

The executable is not code-signed, so SmartScreen may show a warning. If you trust the source, choose "More info" then "Run anyway". The full SHA-256 is published with each release.

Do I need administrator rights?

Only for lock-screen sync and for running elevated at sign-in. Wallpaper and cursor switching work without admin.

Will it change my wallpaper right away?

No. Lida does nothing until you pick a wallpaper and cursor scheme for each mode. Until then your desktop stays as it is.

Which cursor schemes can I use?

Any scheme already installed in Windows. Type its exact name, as shown under HKCU\Control Panel\Cursors\Schemes.

How do I uninstall it?

Turn off "Start with Windows", exit Lida from the tray menu, then delete Lida.exe and %APPDATA%\Lida.
